2. Drawing tools

Usage:
Draw: left-click and drag. Hold Shift for horizontal/vertical.
Chain lines: activate the option and draw the first line. Every following line starts exactly at the previous endpoint. Click End chain to start a new chain.
There is no automatic snapping to unrelated lines or endpoints.
Edit vertices: endpoints and shared vertices are shown as small points. Drag a point to move it. Only connected segments in the same chain move together.
Select line: click close to a line, then delete it.
Pan: right-click and drag. Undo: Ctrl+Z. Delete: Delete key.
